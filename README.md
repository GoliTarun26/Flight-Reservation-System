# Flight-Reservation-System

The Flight Reservation Management System is a console-based C application designed to manage flight information and passenger reservations efficiently using a Binary Search Tree (BST) data structure.

Each flight is represented as a node in the BST, organized based on its flight number for fast searching, insertion, and traversal. Passengers of each flight are stored in a linked list, enabling dynamic addition and removal of passengers.

The system allows users to perform key operations such as viewing available flights, booking seats, canceling reservations, and checking reservation details.

Here are the **Key Features** of the project:

1. **Flight Management using BST:**

    Flights are stored in a Binary Search Tree for fast searching, insertion, and display.

2. **Passenger Management using Linked List:**

    Each flight maintains a linked list of passengers with their names and seat numbers.

3. **Seat Booking:**

    Allows booking seats for passengers until the flight reaches its capacity.

4. **Reservation Cancellation:**

    Enables passengers to cancel their booking and updates seat availability.

5. **Reservation Status Display:**

    Shows flight details, booked seats, and passenger information.

6. **Display All Flights:**

    Displays all available flights in ascending order of flight numbers.

7. **Menu-Driven Interface:**
   Simple and user-friendly menu for easy interaction.
